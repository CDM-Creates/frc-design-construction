# INOV8 Architecture Site

A cinematic architecture website built from the supplied project drawing sets.

## Open in VS Code

1. Open this folder in VS Code.
2. Open the integrated terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local address shown in the terminal.

## Included

- Scroll-driven Kingsford project story
- Architectural drawing-to-streetscape transition
- Responsive project case study
- Transparent interactive project estimator
- Interactive client portal concept
- Project roadmap enquiry form
- Mobile and reduced-motion support

The estimate and portal currently demonstrate the client experience with sample
data. Connect them to your preferred database, email service and authentication
provider before using them with real clients.
